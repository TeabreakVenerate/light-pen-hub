# Technology Stack

| Category | Technology | Purpose |
| :--- | :--- | :--- |
| Framework | Next.js (App Router) | Core React framework, routing, API logic. |
| Styling | Tailwind CSS | Utility-first styling and dynamic color shifting. |
| UI/Animations | 21st.dev & Framer Motion | 2.5D interactive components and UI state transitions. |
| Database | Supabase (PostgreSQL) | Storing comments, user profiles, and tracking gifts. |
| Real-Time | Supabase Subscriptions | Powering live comment feeds and ranking leaderboards. |
| Authentication | Clerk | Secure user login for commenting and gifting. |
| Payments | Stripe | Handling the per-book gift micro-transactions. |
| Analytics | Google Analytics & Clarity | Tracking traffic and visualizing UI interaction. |
| Deployment | Vercel | Seamless hosting and CI/CD via GitHub. |
